# Building Mo3D

Complete build instructions for **Linux** and **macOS**.

## Prerequisites

### All Platforms
- **CMake** 3.20 or later
- **C++17** compatible compiler
- **vcpkg** for dependency management

### Platform-Specific

#### Linux (Ubuntu/Debian)
```bash
sudo apt-get update
sudo apt-get install -y \
    build-essential \
    cmake \
    pkg-config \
    libgl1-mesa-dev \
    libglu1-mesa-dev \
    libx11-dev \
    libxrandr-dev \
    libxinerama-dev \
    libxcursor-dev \
    libxi-dev \
    libasound2-dev
```

#### macOS
```bash
# Install Xcode Command Line Tools
xcode-select --install

# Install Homebrew (if not already installed)
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# Install CMake
brew install cmake pkg-config
```

## vcpkg Setup

### Install vcpkg (One-time setup)

```bash
# Clone vcpkg
git clone https://github.com/Microsoft/vcpkg.git ~/vcpkg
cd ~/vcpkg

# Bootstrap vcpkg
./bootstrap-vcpkg.sh  # macOS/Linux

# Add to PATH (add to ~/.bashrc or ~/.zshrc for persistence)
export VCPKG_ROOT=~/vcpkg
export PATH=$VCPKG_ROOT:$PATH
```

## Building Mo3D

### Quick Build (Recommended)

```bash
cd mo3d
mkdir build && cd build

# Configure with vcpkg
cmake .. -DCMAKE_TOOLCHAIN_FILE=$VCPKG_ROOT/scripts/buildsystems/vcpkg.cmake

# Build (use all CPU cores)
cmake --build . --config Release -j$(nproc)  # Linux
cmake --build . --config Release -j$(sysctl -n hw.ncpu)  # macOS

# Run
./mo3d
```

### Manual Dependency Installation (Alternative)

If you prefer not to use vcpkg, install dependencies manually:

#### Linux
```bash
sudo apt-get install -y \
    libglfw3-dev \
    libglm-dev \
    libfreetype-dev \
    nlohmann-json3-dev

# RtMidi and ImGui may need manual installation
```

#### macOS
```bash
brew install glfw glm freetype nlohmann-json

# RtMidi and ImGui may need manual installation
```

Then build without vcpkg:
```bash
mkdir build && cd build
cmake .. -DMO3D_USE_VULKAN=OFF
cmake --build . --config Release
```

## Build Options

```bash
# Disable Vulkan (OpenGL only)
cmake .. -DMO3D_USE_VULKAN=OFF \
         -DCMAKE_TOOLCHAIN_FILE=$VCPKG_ROOT/scripts/buildsystems/vcpkg.cmake

# Debug build
cmake .. -DCMAKE_BUILD_TYPE=Debug \
         -DCMAKE_TOOLCHAIN_FILE=$VCPKG_ROOT/scripts/buildsystems/vcpkg.cmake

# Verbose build output
cmake --build . --config Release --verbose
```

## Platform-Specific Notes

### macOS
- OpenGL is deprecated on macOS but still works
- Uses OpenGL 4.1 Core Profile
- Metal/MoltenVK support may be added in the future
- If you get "xcrun: error: invalid active developer path", run:
  ```bash
  xcode-select --install
  ```

### Linux
- Requires X11 for windowing (Wayland support via XWayland)
- ALSA required for MIDI support
- OpenGL 4.1+ drivers needed
- For older GPUs, you may need to adjust OpenGL version in `Window.cpp`

## Troubleshooting

### vcpkg Dependencies Not Found
```bash
# Ensure vcpkg is in PATH
echo $VCPKG_ROOT

# If empty, set it:
export VCPKG_ROOT=~/vcpkg

# Re-run CMake
cd build
rm -rf *
cmake .. -DCMAKE_TOOLCHAIN_FILE=$VCPKG_ROOT/scripts/buildsystems/vcpkg.cmake
```

### OpenGL Errors on macOS
```bash
# Ensure you're using Core Profile
# Already configured in src/core/Window.cpp:
# - OpenGL 4.1
# - Core Profile
# - Forward Compatible
```

### MIDI Not Working on Linux
```bash
# Check ALSA is installed
apt list --installed | grep alsa

# List MIDI devices
aconnect -l

# Install ALSA if missing
sudo apt-get install libasound2-dev
```

### Build Errors

**CMake can't find OpenGL:**
```bash
# Linux
sudo apt-get install libgl1-mesa-dev

# macOS - should be automatic via Xcode
```

**Undefined reference to pthread:**
```bash
# Already handled in CMakeLists.txt for Linux
# If issue persists, manually add:
target_link_libraries(mo3d PRIVATE pthread)
```

**ImGui linking errors:**
```bash
# Ensure vcpkg installed ImGui with GLFW backend
vcpkg install imgui[glfw-binding,opengl3-binding]
```

## Performance

### Recommended Settings
- **VSync**: ON (default) for smooth 60 FPS
- **MSAA**: 4x (default) for good quality
- **Resolution**: 1920x1080 for best performance

### Low-End Systems
Edit `src/core/Application.cpp`:
```cpp
config.width = 1280;
config.height = 720;
config.samples = 2;  // Lower MSAA
```

## IDE Integration

### Visual Studio Code
```bash
# Install C++ extension
code --install-extension ms-vscode.cpptools

# Open project
code .

# Configure IntelliSense to use compile_commands.json
# (automatically generated by CMake)
```

### CLion
- Open CMakeLists.txt as project
- CLion will auto-detect vcpkg toolchain
- Set Build Type to Release for better performance

### Xcode (macOS)
```bash
cmake .. -G Xcode \
         -DCMAKE_TOOLCHAIN_FILE=$VCPKG_ROOT/scripts/buildsystems/vcpkg.cmake
open mo3d.xcodeproj
```

## Installation

```bash
# System-wide install (requires sudo)
cd build
sudo cmake --install .

# Run from anywhere
mo3d

# Uninstall
sudo rm /usr/local/bin/mo3d
sudo rm -rf /usr/local/share/mo3d
```
